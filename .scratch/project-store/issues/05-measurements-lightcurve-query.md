## Comments

Implemented in `src/seestar_controller/store/measurements.py` (pure Python, stdlib only; no GTK / no link imports, subprocess-enforced in tests), `MeasurementError(ProjectError)` added to `errors.py`, all exported from `store/__init__.py`. The `measurements` table already existed in `schema.py` (frame FK, jd, mag, mag_err, excluded) — no schema change. API: `Measurement` frozen dataclass `(id, frame_id, session_id, jd, utc, mag, mag_err, excluded)` with `session_id`/`utc` joined from the frame; `add_measurement(project, frame_id, mag, jd=None, mag_err=None, excluded=False) -> Measurement` (note: `mag` is positional before the optional `jd`, since Python forbids a non-default after a default); `lightcurve(project, include_excluded=False) -> list[Measurement]`; `set_excluded(project, measurement_id, excluded) -> Measurement`; `measurements_for_frame(project, frame_id) -> list[Measurement]`. Documented choices: (1) `jd=None` defaults to the frame's `jd`, an explicit `jd` overrides (mid-exposure correction) and must be finite — `utc` always comes from the frame; (2) unknown frame raises `MeasurementError` naming the id, checked inside the same transaction as the insert (clear error instead of the raw FK `IntegrityError`), nothing written; (3) validation raises `MeasurementError` with field + value in the message — `mag` finite (NaN/inf rejected), `mag_err` None or finite `>= 0`, explicit `jd` finite; structural type errors (`frame_id` not int, `excluded`/`include_excluded` not bool) raise `TypeError`; (4) `lightcurve` orders by `jd` (ties by row `id`) across ALL sessions via `JOIN frames`, excluded points filtered unless `include_excluded=True`; (5) `set_excluded` flags/unflags in one transaction, unknown id raises `MeasurementError`; (6) `measurements_for_frame` with an unknown frame is a filter, not an error — returns `[]` (same semantics as `list_frames` with an unknown session); (7) all mutations run in one transaction (`with project.db:`). Tests: `tests/test_store_measurements.py` (48 tests, tmp_path only, no network; frames inserted as db rows directly, sessions via `start_session` with a frozen clock): append + returned record + raw db row, jd default from frame / explicit override (utc still from frame), mag_err None → NULL, excluded at insert, int→float coercion, unknown frame → `MeasurementError` with nothing written, NaN/inf mag rejected, non-numeric mag rejected, bad mag_err (NaN/inf/negative) rejected, non-finite jd rejected, bad argument types → `TypeError`, empty lightcurve, multi-session merge ordered by jd with session_id/utc joined (appended out of order), jd ties broken by id, exclusion filtering + `include_excluded=True`, `include_excluded` non-bool → `TypeError`, `set_excluded` flag/unflag round-trip with db row + lightcurve reflection, unknown id → `MeasurementError`, bad types → `TypeError`, `measurements_for_frame` per-frame ordered + unknown frame → `[]` + bad id → `TypeError`, persistence across reopen (full records, flag/unflag + append still work), public-API export test (incl. dataclass field order), module-boundary subprocess test. `uv run pytest`: 675 passed (627 + 48).
