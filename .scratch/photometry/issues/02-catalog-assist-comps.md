**What to build:** standard-star suggestions — given the target's coordinates, list nearby AAVSO/VizieR standard stars from the catalog module; clicking a suggestion adds it as a comparison star. Demoable: with mocked catalog, suggestions appear next to the image and can be added as comps.

## Comments

Strict pure/widget split kept (subprocess + source-scan enforced in `tests/test_photometry_picking.py`):

- Pure `photometry/suggest.py` (stdlib + catalog + picking only, NO gi; the catalog facade is imported lazily inside `default_standards_lookup`, and tests inject a mocked `lookup` callable — no network): `SuggestionError(PhotometryError)`; frozen `CompSuggestion(name, coord, magnitude, band, distance_deg)` with `describe()`; frozen `SuggestionSnapshot(target, radius_deg, suggestions, error)`; `SuggestionController(picker_controller=None, *, lookup=None, radius_deg=1.5, search_runner=None)` — follows the shared `PickController` (re-searches when the target pick's sky coord changes), `refresh()` runs the cone search synchronously and catches ANY lookup exception (e.g. `CatalogUnavailableError`) into a clean `snapshot.error` string with empty suggestions (never a traceback, recovers on the next refresh), re-filters every returned star against the radius with `angular_distance` (1e-6 deg epsilon for WCS float noise) and sorts nearest-first (tie-break name); `add_suggestion(index)` validates the index, guards against adding the same star twice (1e-9 deg), and adds it as a comp via `PickController.add_at_sky(coord, role="comp", label=name, snap=False)` — sky->pixel via `sky_to_pixel` against the current frame WCS, out-of-frame/duplicate wrapped into `SuggestionError` (chained `PickingError`); `set_radius` (validated (0,180], rejects str/bool, no-op when unchanged, re-searches when a target is set); listeners idempotent/isolated with frozen snapshots; `search_runner` injectable so automatic searches can run off the main loop. `PickController.add_at_sky` added in `picking.py` (ticket-01 semantics kept: comps accumulate, one target).
- Widget `photometry/suggestions_panel.py` (gi at top, lazy PEP 562 export via `_WIDGET_EXPORTS` as `photometry.SuggestionsPanel`): `SuggestionsPanel(Gtk.Box)` — Search button + radius label + one ListBox row per suggestion (description + Add button) + status label (clean catalog error in the `error` css class). The Search button runs the blocking `refresh()` on a daemon worker thread and marshals listener notifications back with `GLib.idle_add`; the panel also registers its worker-thread `search` as the controller's `search_runner`, so automatic searches (target changed, radius changed) never block the main loop. Add button -> `add_suggestion(index)` -> comp pick at the WCS pixel.
- Settings: new key `photometry_comp_search_radius_deg` (string, default `"1.5"`, validated `(0, 180]` via `validate_comp_search_radius` in `ui/state.py`, constants `DEFAULT_COMP_SEARCH_RADIUS_DEG`/`MAX_COMP_SEARCH_RADIUS_DEG`, dialog field in `ui/settings_dialog.py`); the pure layer stays settings-agnostic — `ui/settings.py` helper `comp_search_radius_deg(values)` (never raises, falls back to the default) injects the value.
- Wiring: `SeestarApplication` owns the shared `suggest_controller = SuggestionController(picker_controller=self.picker_controller, radius_deg=comp_search_radius_deg(settings values))` and keeps the radius in sync via a settings listener (`set_radius`); `SeestarWindow` takes/passes it to `build_view(view.id, ..., suggest_controller=...)`; `PhotometryView` forwards it to `StarPickerView`, which appends the `SuggestionsPanel` in the left pane (default: a fresh controller bound to its own pick controller when standalone).
- Tests: `tests/test_photometry_suggest.py` (34 pure headless: radius validation, sorted/radius-filtered suggestions from a mocked lookup, edge star kept, malformed stars skipped, `set_radius` re-search, `CatalogUnavailableError` -> clean error snapshot + recovery, `add_suggestion` sky_to_pixel round-trip on a synthetic WCS + comps accumulate + duplicate guard + error paths, follows target changes, `search_runner`, listeners, default lookup delegates to the facade, save/load round-trip with a catalog-added comp on a tmp project, subprocess + source-scan no-gi boundary) and `tests/test_photometry_widgets.py` extended (importorskip gi; skips in sandbox, runs on desktop/xvfb: build_view/app/window share one suggest controller + live radius sync from settings, panel lists mocked suggestions nearest-first, Add button adds the comp at the exact WCS pixel, catalog failure -> error css status, Search button runs the lookup on a worker thread).
