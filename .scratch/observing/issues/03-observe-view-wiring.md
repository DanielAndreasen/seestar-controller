## Comments

New pure module `src/seestar_controller/observing/observe_controller.py` (executor layer: no gi, imports link + ui.connection/ui.notifications + `.executor`; lazy PEP 562 export from `observing/__init__.py` via `_EXECUTOR_EXPORTS`, so the package import stays link-free — subprocess + source-scan enforced in test_observing_queue.py):

- `ObserveController(connection, queue_controller, bus=None, *, executor_factory=None, preview_stream_factory=None, invoke_on_main=None, preview_max_fps=10.0)` — the app-level shared instance (like `ConnectionController`): `start_night(project=None, **executor_kwargs)` (guards: connected + project + no night in flight, else `ObserveStateError`; builds the `NightExecutor` via the injectable factory with the queue controller's resolver and the controller's `invoke_on_main`, subscribes, starts the preview stream best-effort, starts the executor), `pause()/resume()/skip()/stop()` passthroughs (no-ops when idle), `park()` → `device.park()` via the connection (raises when disconnected), `stop_preview()`, `set_project()`, `add_listener`/`remove_listener` (view state) + `add_preview_listener`/`on_preview_frame` (decorator form), properties `executor`/`stream`/`latest_frame`/`project`/`night_active`/`preview_running`/`snapshot`.
- Frozen `ObserveViewState(executor_state, queue_index, entry, frames_stacked, elapsed_s, error, session, queue_entries, preview_frame, preview_running, night_active)` emitted to the view listeners on any change — executor transition/tick, preview frame available, queue change — all callbacks marshalled through `invoke_on_main` (`GLib.idle_add` in the app). Preview frames: `PreviewFrame` passed through, raw `Frame` decoded via `link.preview.decode_payload`; `latest_frame` always updated, listener notification throttled by `FrameThrottle(preview_max_fps)`. Executor DONE/ABORTED stops the preview and pushes an info/error notification ("Night finished"/"Night aborted"); preview-start failure is a warning notification, the night still runs (documented choice). `default_preview_stream_factory(device, host)` builds a real `PreviewStream` from the connected scope host (`connection.scope_ip` or `device.transport.host`); `format_target`/`format_elapsed` label helpers.
- Widget `observing/observe_view.py` (gi at top, lazy `_WIDGET_EXPORTS`): `ObserveView(observe_controller, *, queue_controller=None, project=None)` — a `Gtk.Paned` (documented choice over `Adw.OverlaySplitView`: both panes stay visible on a wide window): left = `QueueEditor` + Start night / Pause-Resume toggle / Skip / Stop / Park buttons + inline status label; right = `Gtk.Picture` in an overlay with a "no preview yet" placeholder (frame ndarray → PNG via PIL → `Gdk.Texture.new_from_bytes`) + "Night progress" `Adw.PreferencesGroup` (target, state, sub-frames stacked, elapsed, queue position, session). Re-renders on every `ObserveViewState` snapshot; never blocks the main loop (executor + preview sockets live on their own threads).
- Wiring: `SeestarApplication.observe_controller = ObserveController(connection_controller, queue_controller, notification_bus, invoke_on_main=GLib.idle_add)`; `SeestarWindow` takes/passes it via `build_view(view.id, queue_controller=..., observe_controller=...)`; `ui/views.py` `ObserveView` wraps the widget and keeps the `queue_controller`/`queue_editor` properties.
