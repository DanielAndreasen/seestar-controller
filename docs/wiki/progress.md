- 2026-11-19: **02 PEM key management** — implemented `9665b2e`. 81 tests green. Key path resolution: explicit arg > `SEESTAR_KEY_PATH` env var (same name seestarpy auto-discovers) > `~/.config/seestar-controller/key.pem`. Missing/invalid key raises `MissingKeyError`/`InvalidKeyError` naming the extraction step (`python -m seestarpy.extract_pem <apk>` / `uv run seestar-controller extract-key <apk>`); key file written 0600 (chmod after write so pre-existing looser files are tightened). Extraction implements seestarpy's documented flow locally (seestarpy is not a dependency): APK/XAPK as zip → strings-scan `lib/*/libopenssllib.so`, fallback to all entries, XAPK nested base APKs; first block parsing as an unencrypted RSA private key wins. CLI: `seestar-controller extract-key <apk|xapk> [--key-path P] [--force]` (console script + `python -m seestar_controller`), plus `key-path`. Transport loads the handshake key via `keys.load_key()` so `connect()` signs with the configured key; `pem=`/`private_key=` overrides kept for tests. Still unverified against a real app package / real scope (user AFK).

- 2026-11-19: **04 stacking control** — implemented `5d3b33d`. 112 tests green (99 + 13). New `link/stacking.py` holds the stacking wire contract shared by facade and mock: `iscope_start_stacking` / `iscope_stop_stacking` RPCs, pushed `Stack` progress event (`state`/`lapse_ms`/`frames`), and the validated ranges (exposure 1–60 s sent as `exp_ms`, gain 0–100, mosaic pan/tilt 0–10°; ranges are the mock's contract, unverified against real hardware). `Device.start_stack(exposure, gain, mosaic)` validates client-side (`ValueError`, nothing sent), sends the RPC and returns the state once mode is `stacking`; `mosaic` is a bool or a `(pan, tilt)` framing in degrees. `Device.stop_stack()` → mode `idle` + final `Stack` event. Progress reaches callers three ways: raw `add_event_handler("Stack", ...)`, typed `add_stacking_progress_handler` / `@on_stacking_progress` delivering parsed `StackingProgress` (frames stacked, elapsed), and `state().stacking` (`DeviceState.stacking_active`). MockScope grew `start_stacking(exposure, gain, mosaic)` (validates ranges, rejects "already stacking", mode→stacking, records `last_stack_params`, pushes `Stack` events per simulated 10 s sub-frame via `stack_event_interval`/`subframe_ms` knobs) and `stop_stacking()` (mode→idle, final event); invalid wire params rejected with non-zero reply code → `RpcError`. Demo extended: `python -m seestar_controller.link.device` now connect→goto→start_stack→watch progress→stop_stack→park. Still mock-only (user AFK).
